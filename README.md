# Camadas Legais

PROJETO: SITE OFICIAL DO PODCAST “ALÉM DO FEED”

Quero que você projete e construa um site completo, moderno, responsivo e profissional para um podcast universitário brasileiro de Direito Digital chamado:

ALÉM DO FEED

O projeto é desenvolvido por estudantes de Direito para a disciplina de Direito Digital.

O tema central do podcast é:

“Redes sociais e proteção da imagem: quais são os limites para publicar e compartilhar conteúdos sobre outras pessoas?”

O site não deve parecer um trabalho de faculdade.

Ele deve parecer uma mídia digital jurídica independente, contemporânea e voltada para jovens, com presença editorial própria.

1. IDEIA CENTRAL DA MARCA

O conceito do “Além do Feed” é:

Nem tudo que aparece no feed termina no feed.

Uma publicação aparentemente simples pode esconder questões como:

direito à imagem;

privacidade;

honra;

intimidade;

consentimento;

proteção de dados;

liberdade de expressão;

responsabilidade civil;

responsabilidade penal;

direito autoral;

consequências jurídicas.

O conceito visual do projeto é:

O FEED É A SUPERFÍCIE. O DIREITO ESTÁ ALÉM DELA.

Portanto, o site deve funcionar como uma experiência em camadas.

O usuário entra vendo a superfície:

POST
VÍDEO
FOTO
TÍTULO
FEED

Mas pode clicar para descobrir:

CONTEXTO
LEI
JURISPRUDÊNCIA
RISCO
CONSEQUÊNCIA

Essa transição entre “feed” e “além” deve ser o grande diferencial do site.

2. OBJETIVO DO SITE

O site deve cumprir simultaneamente cinco funções:

apresentar o podcast;

explicar juridicamente o tema;

servir como hub dos episódios;

reunir conteúdos de Instagram e YouTube;

funcionar como uma experiência visual coerente com a identidade do “Além do Feed”.

O site deve permitir que alguém que nunca ouviu falar do projeto entenda rapidamente:

“Eles falam sobre as consequências jurídicas daquilo que fazemos nas redes sociais.”

3. PÚBLICO

Público principal:

criadores de conteúdo;

A linguagem deve ser acessível.

Não utilizar juridiquês desnecessário.

Mas também não infantilizar o conteúdo.

7. PRINCÍPIO VISUAL MAIS IMPORTANTE

O site deve parecer inicialmente um feed editorial, mas não simplesmente copiar o Instagram.

coração do Instagram;

interface 1:1;

botão de like idêntico;

comentários idênticos;

18. YOUTUBE

Criar uma seção:

ASSISTA

Os vídeos do YouTube devem ser incorporados utilizando o player oficial do YouTube, quando o vídeo permitir incorporação.

Não baixar os vídeos.

Usar embed oficial.

A documentação do YouTube disponibiliza o player incorporável e inclusive a informação de que vídeos podem possuir o status de embeddable.

Criar componente reutilizável:

YouTubeEmbed

Recebe:

videoId;

title;

aspectRatio.

O player deve ser responsivo.

19. INSTAGRAM

Criar uma seção:

Não copiar a interface do Instagram.

Criar cards com:

botão para abrir no Instagram.

Quando um conteúdo puder ser incorporado oficialmente, utilizar o mecanismo oficial de embed.

Não depender de scraping.

Não armazenar cópias dos vídeos do Instagram no servidor sem necessidade.

Se o embed oficial não estiver disponível ou deixar de funcionar, utilizar fallback:

VER NO INSTAGRAM →

O site deve continuar funcionando mesmo que o Instagram altere limitações de incorporação.

20. IMPORTANTE SOBRE INSTAGRAM

Não assumir que existe uma API pública simples para:

“buscar automaticamente todos os Reels do perfil e reproduzi-los como se fossem vídeos nativos do nosso site”.

Projetar a arquitetura para permitir três possibilidades:

OPÇÃO A

Embed oficial.

OPÇÃO B

Cards com thumbnail + link para Instagram.

OPÇÃO C

Conteúdo manualmente cadastrado no painel/site.

A arquitetura deve permitir mudar de A para B ou C sem refazer o site inteiro.
